# myHoodora logo system: file index

Every asset lives in `<folder>/SVG`, `/PDF`, `/PNG_4K` (longest side 3840 px) and, where a platform needs exact dimensions, `/PNG_Exact` (size in the file name). File names follow `myhoodora_<type>_<variant>.ext`.

## 01_Primary  ·  Primary logos

| Asset (file name stem) | Formats | Best use |
|---|---|---|
| `myhoodora_logo_horizontal_fullcolor` | PDF, PNG 4K, SVG | Default logo. Websites, documents, decks, signage on light backgrounds (#FFFFFF–#F2F2F2). |
| `myhoodora_logo_horizontal_reversed` | PDF, PNG 4K, SVG | Teal (#147C73) or dark backgrounds: headers, banners, video end-cards. |

| `myhoodora_logo_stacked_reversed` | PDF, PNG 4K, SVG | Square-ish spaces on teal/dark backgrounds: splash screen, merch, event backdrops. |
