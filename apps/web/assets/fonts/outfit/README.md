# Outfit (brand font) for generated images

The link-preview and badge images (`opengraph-image.tsx` routes) are drawn by `next/og`, which needs the
font as a file: these are the TTFs from `@expo-google-fonts/outfit` (the mobile app's font package).

Outfit is by the Outfit Project Authors and licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). The npm package that ships them is MIT (`LICENSE-expo-google-fonts.txt`).
