# iPhone bezels

Apple's official iPhone 17 Pro Max frames, used by `../app-store-header.html` and `../app-store-search.html`.
They're Apple's files, so they aren't committed (see `.gitignore`). To get them:

1. Download "iPhone 17" from Apple Design Resources → Product Bezels: https://developer.apple.com/design/resources/
   (`Bezel-iPhone-17.dmg`; opening it asks you to accept Apple's licence).
2. Copy from `PNG/iPhone 17 Pro Max/` into this folder, renamed:
   - `iPhone 17 Pro Max - Cosmic Orange - Portrait.png` → `iphone-17-pro-max-cosmic-orange-portrait.png`
   - `iPhone 17 Pro Max - Silver - Portrait.png` → `iphone-17-pro-max-silver-portrait.png`
   - `iPhone 17 Pro Max - Deep Blue - Portrait.png` → `iphone-17-pro-max-deep-blue-portrait.png`

Each is 1470 × 3000 with the screen opening at x 75, y 66, 1320 × 2868: exactly the simulator screenshots in
`../../screenshots-ios/`, so they drop in at 100%. Apple asks that marketing using bezels follows its Marketing
Resources and Identity Guidelines: https://developer.apple.com/app-store/marketing/guidelines/
