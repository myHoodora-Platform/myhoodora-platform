# Hood Content Bank

_Ready-to-post content for the **myHoodora Hood Team** account. Plan and rules: [hood-activation-plan.md](hood-activation-plan.md). Written for Lagos (122 Hoods) and Ibadan (56 Hoods)._

## How to use this file

- **Every item here is posted only by the official Hood Team account**, which carries the "Official · Hood Team" label. Never copy these into a personal account to look like a neighbour.
- `{hood}` and `{city}` are filled in automatically.
- `[FILL: …]` means a moderator must add the local detail **and check it is current** before the item is scheduled. Never post a phone number you haven't checked.
- Keep the tone warm, plain and local. Write the way a friendly estate chairman talks, not like a bank's marketing team.
- Each item has a code (`W01`, `S12`…) so the admin content bank, schedules and reports can refer to it.

**Format (the admin import reads this):**

```
### CODE · tag · category[ · pin Nd][ · poll Nd]
Body text (one or more lines)
Poll: Option A | Option B | Option C
```

- **tag**: `welcome` · `starter` · `info` · `daily` · `festive`
- **category**: `general` · `recommendation` · `for_sale` · `event` · `lost_found` · `poll`
- **Polls**: 2–4 different options, open for up to 7 days.
